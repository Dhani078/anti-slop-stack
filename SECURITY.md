# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within `anti-slop-stack`, please open a private security advisory on GitHub or email the maintainer at `dhanisepeda@gmail.com`. All security advisories will be promptly investigated and addressed.
